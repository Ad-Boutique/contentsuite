So funktioniert es
  1. Klicken Sie auf einen Satz oder ein Vorschaubild: Das Video springt an diese Stelle.
  2. Ordnen Sie jede Passage ein: Muss rein, Optional oder Raus. Unter „Kommentar“ können Sie Hinweise ergänzen (z. B. „nur der erste Satz“).
  3. Links sehen Sie laufend, wie lang Ihre Auswahl ist, im Vergleich zur Ziel-Länge. Mit „Auswahl abspielen“ sehen Sie einen groben Zusammenschnitt.
  4. Optional: Über „Reihenfolge“ können Sie Passagen umstellen (1, 2, 3 …). Ohne Angabe bleibt die Reihenfolge der Langversion.
  5. Fertig? Ihre Auswahl ist für alle Beteiligten sofort sichtbar, auch für Ad Boutique. Mehrere Personen können gleichzeitig arbeiten. Zusätzlich können Sie die Liste kopieren und per Mail schicken.
